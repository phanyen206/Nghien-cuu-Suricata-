# 06. Tổng hợp kết quả thực nghiệm

Thư mục này giúp người đọc tra cứu kết quả cuối cùng của 13 kịch bản và so sánh các lần chạy.

## Thành phần
- `Bang-tong-hop.md`: bảng trạng thái phát hiện, luật/SID, minh chứng và kết quả theo từng KB.
- `Hinh-anh-so-sanh/`: biểu đồ và hình được sử dụng trong phần đánh giá.

## Cách đọc kết quả
1. Chọn mã KB và mở README tương ứng trong mục 03.
2. Đọc kết quả Run 1 (ET Open) và Run 2 (ET Open + luật riêng) nếu kịch bản có hai lần chạy.
3. Kiểm tra PCAP, EVE JSON hoặc ảnh gốc được liên kết trong README KB.
4. Chỉ so sánh các lần chạy có cùng dữ liệu đầu vào và điều kiện cấu hình tương đương.

Các ô “Chờ đối chiếu” trong bảng tổng hợp có nghĩa là chưa xác minh đủ minh chứng; không phải kết quả bằng 0.
